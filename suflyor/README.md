# Клиент Суфлёра

Аудио распознаётся только Whisper на устройстве. Анализ текста выполняет DeepSeek через серверный `/api/analyze`; ключ не передаётся браузеру.

Не размещайте эту папку отдельно как статический сайт: для автоматического конвейера нужен сервер. Инструкции запуска и Timeweb находятся в корневом README.md.
